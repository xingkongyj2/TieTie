# Reminder title font

- Family: ZCOOL KuaiLe (站酷快乐体), Regular, normal, weight 400.
- License: SIL Open Font License 1.1; original upstream notice is preserved in `OFL.txt`.
- Subset characters: 待、完、成、已、提、醒、我、们、他、贴、清、单、的、纪、念、日、登、录、注、册、关、于 (`U+5F85`, `U+5B8C`, `U+6210`, `U+5DF2`, `U+63D0`, `U+9192`, `U+6211`, `U+4EEC`, `U+4ED6`, `U+8D34`, `U+6E05`, `U+5355`, `U+7684`, `U+7EAA`, `U+5FF5`, `U+65E5`, `U+767B`, `U+5F55`, `U+6CE8`, `U+518C`, `U+5173`, `U+4E8E`).
- Used by: 提醒页的艺术标题和三个分类 tab（提醒/纪念日/贴贴）、提醒页的「待完成 / 已完成」分组标题、「我的」页标题和「关于我」小节标题、绑定引导页的「贴贴清单」、登录页标题和「登录 / 注册」切换 tab。新增字形时要重新生成覆盖全部用字的子集，否则缺失的字会静默回退成系统字体。
- This WOFF2 was provided by the Google Fonts official `text` subset API. It is served locally by the app; no runtime external font requests are needed.
